# # 🧩 Puzzle Game

Тестовое задание, выполненное на Unity.

##  Особенности

* Реализована основная игровая механика сборки пазла.
* Простая и понятная структура проекта.
* Акцент на стабильность и корректную работу игрового процесса.

##  Использование ИИ

В процессе разработки использовались 3 AI-инструмента для ускорения работы, генерации звуков и изображений .

Основная игровая логика (CORE) была написана и доработана вручную для обеспечения надежности и полного контроля над результатом.

## ⏱️ Время разработки

На выполнение задания было затрачено около **2 часов**, включая разработку, тестирование и исправление ошибок.

## 📌 Итог

Проект демонстрирует навыки разработки игр на Unity, работы с C# и способность быстро создавать рабочие игровые механики с использованием современных инструментов разработки.
